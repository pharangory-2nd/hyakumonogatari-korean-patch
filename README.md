# 백물어 텍스트 한글패치

PC엔진 CD용 **『백물어 — 정말로 있었던 무서운 이야기』**의 비공식 한국어 패치입니다.

현재 버전은 **v0.1.8 베타**이며, 우선 게임 본문을 한국어로 읽을 수 있도록 제작했습니다. 「2층이 무서워」·「팔 내놔」·「인형은 밤마실을 간다」·「선택받은 집」의 음성 대사에 자막을 추가했으며, 나머지 음성 번역·자막과 일부 메뉴·그래픽 한글화는 이후 작업으로 남아 있습니다.

## v0.1.8 변경 사항

이번 버전에서는 「선택받은 집」의 음성 대사에 한국어 자막을 추가하고, 「팔 내놔」의 음성 자막과 「귀신 들린 마을」의 본문 번역 일부를 수정했습니다.

기존 번역과 「2층이 무서워」·「팔 내놔」·「인형은 밤마실을 간다」의 음성 자막, 메인 타이틀 한글화, 이전 버전의 BGM·연사 입력 관련 버그 수정도 모두 포함합니다.

작업 중인 에피소드 진입 제목 한글화는 이번 배포에 포함하지 않습니다.

**일본판 원본에 새로 패치해야 합니다. 기존 한글패치 이미지나 테스트용 이미지에 덧씌우지 마십시오.**

## 다운로드

이 저장소의 **Releases**에서 `v0.1.8` 베타를 선택하고, Assets에 첨부된 **`Hyakumonogatari_Korean_Text_v0.1.8.zip`**을 받으십시오.

GitHub가 자동으로 제공하는 `Source code (zip)`은 설치용 패치 파일이 아닙니다.

## 설치 방법

패치 실행 환경은 Windows이며, 별도 Python 설치나 관리자 권한은 필요하지 않습니다.

1. 지원하는 원본 CUE와 28개 BIN을 한 폴더에 준비합니다.

2. 패치 ZIP의 **내용물**을 같은 폴더에 풉니다. `Run-Patch.cmd`가 원본 CUE와 나란히 있어야 합니다.

3. `Run-Patch.cmd`를 더블클릭하고 검사가 끝날 때까지 기다립니다.

4. `SUCCESS`가 표시되면 새로 생성된 `HyakuMonogatari_Korean_Text_v0.1.8` 폴더 안의 CUE로 게임을 실행합니다.

원본 파일은 수정하지 않습니다. 출력 폴더에는 모든 트랙이 복사되므로 이 폴더만 옮겨 사용할 수 있습니다. 약 1GB 이상의 여유 공간을 권장합니다. 출력 폴더가 이미 있으면 덮어쓰지 않고 중단합니다.

BIOS를 수정하거나 교체하는 패치가 아닙니다. 번역용 Lua 스크립트도 필요하지 않습니다. 패치 적용 후에는 이전 버전의 즉시 저장 상태를 불러오지 말고 CUE에서 정상 부팅해 주십시오.

## 일반 메뉴(개방된 에피소드 선택화면) 진입 방법

1. 타이틀 화면에서 **RUN 버튼**을 눌러 촛불이 늘어선 화면으로 들어갑니다.

2. 촛불 화면에서 **SELECT 버튼**을 누르면 **개방된 에피소드 선택화면**이 열립니다. 이번에 한글화한 에피소드 제목은 이 목록에 표시됩니다.

3. **방향키 위·아래**로 제목을 고르고 **I 버튼**으로 해당 에피소드에 들어갑니다.

화면의 제목은 개방된 에피소드 수에 따라 달라집니다. 목록은 게임의 진행 기록에 따라 달라집니다. 기록이 없는 상태에서는 **‘데이터 없음’**이 표시될 수 있습니다. 에뮬레이터에서는 키보드의 특정 키가 아니라 PC엔진 패드의 **RUN / SELECT / I**에 배정한 버튼을 사용하십시오.

## 지원하는 원본

**Redump에 등재된 일본판 디스크의 덤프 정보를 기준으로 제작했습니다.** 대상은 `Hyaku Monogatari - Honto ni Atta Kowai Hanashi (Japan)`의 **28 BIN + CUE** 형식입니다.

파일명과 파일 내용이 패키지의 `localization-manifest.json`에 기록된 원본과 정확히 일치해야 합니다. 단일 BIN, ISO, CHD 및 다른 덤프는 이 버전에서 직접 지원하지 않습니다.

패치 프로그램은 다음 항목을 검사합니다.

- 적용 전: 원본 전체 파일의 크기, SHA-1, SHA-256 및 패치 데이터의 SHA-256

- 적용 후: 생성된 전체 파일의 크기, SHA-1, SHA-256

검사를 통과하지 못하면 완료된 출력 폴더를 만들지 않습니다. 실패한 작업의 임시 폴더 `.hyaku-patch-partial-*`가 남을 수 있습니다. 원본 파일명을 바꾸는 것만으로 다른 덤프를 지원하게 되지는 않습니다.

## 한글화 범위

- 일반 에피소드 본문과 「속 영원한 원념」

- 학교 7대 불가사의 본문과 최초 진입 도입부

- 심령현상 지도 본문과 평가 문구

- 반각 공백·마침표·쉼표, 문단 구분 아이콘과 페이지 배치 조정

- 「속 영원한 원념」의 수동 지정 페이지 분할

- 메뉴 에피소드 제목 100개와 ‘데이터 없음’ 안내

- 본문 ‘씨’ 띄어쓰기 및 이름·호칭의 자연스러운 줄바꿈

- 메인 타이틀 부제·감수 표기·특전 메뉴 및 번역자 표기

- 「2층이 무서워」·「팔 내놔」·「인형은 밤마실을 간다」·「선택받은 집」의 음성 대사 자막

본문 한글화에 더해 메뉴 제목을 적용했습니다. 항목 수는 에피소드 수나 실제 화면 수와 다릅니다.

## 아직 포함하지 않은 내용

- 위 네 에피소드에 적용한 자막 이외의 음성 시나리오 및 중간 ADPCM 음성 번역·자막

- 특전 모드 내부 안내·항목·결과 화면, 에피소드 진입 시 큰 제목 그래픽, `第~話`, `~の記憶`, 일부 선택 화면 문구 등

- 「저주의 고쿠리 씨」의 `コロス / ヒロコ / コロセ` 그래픽 연출

- 지도 선택 화면 지명 13개, 시스템 경고 3개, 미사용 개발용 문구 3개

음성 에피소드의 구동 확인은 음성 자막이 구현되었다는 의미가 아닙니다. 위 항목의 일본어 표시는 현재 버전의 미적용 범위입니다.

## 테스트 현황

2026년 10월 28일 v0.1.8 기준입니다.

- Mesen/Lua에서 「선택받은 집」의 자막 10장과 전체 본문 70개 구간을 검증했습니다.

- 통합 이미지에서 「팔 내놔」 전체 본문 115개 구간과 수정 자막, 「귀신 들린 마을」 전체 본문 196개 구간과 수정 문구를 검증했습니다.

- 자막 교체·소거, 본문 진행 및 문단 아이콘 보존을 확인했습니다.

- Windows PowerShell 5.1에서 원본 적용 후 CUE + 28 BIN의 해시, 원본 보존, 기존 결과 덮어쓰기 거부 및 패치된 이미지 입력 거부를 확인했습니다.

- 제작자가 이번 통합본을 RetroArch에서 확인했습니다.

이번 변경으로 모든 에피소드를 다시 검증한 것은 아닙니다. 상세 내용은 검증기록.json을 참고하십시오.

## 오류 제보

저장소의 **Issues → New issue → 오류 제보** 양식을 이용해 주십시오. 양식 이용이 어렵다면 [오류 제보 항목](ERROR_REPORT.md)을 복사해 작성하셔도 됩니다.

패치 버전, 기기 또는 에뮬레이터와 버전, 에피소드명, 문제가 발생한 문구, 재현 순서를 알려 주시면 확인에 도움이 됩니다. 화면 사진이나 짧은 영상도 환영합니다. 원본 디스크 이미지와 BIOS 파일은 첨부하지 마십시오.

## 배포 구성과 글꼴

실행 프로그램(`Run-Patch.cmd`, `Apply-KoreanPatch.ps1`)과 한글화 데이터(`localization-manifest.json`, `localization-data.bin`)를 분리했습니다. 서로 다른 버전의 파일을 섞지 마십시오.

이 배포에는 원본 또는 패치 완료 디스크 이미지, BIOS, 에뮬레이터 및 즉시 저장 상태가 포함되지 않습니다. 게임 이미지와 구동에 필요한 환경은 별도로 준비해야 합니다.
