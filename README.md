# 백물어 텍스트 한글패치

PC엔진 CD용 **『백물어 — 정말로 있었던 무서운 이야기』**의 비공식 한국어 패치입니다.
현재 버전은 **v0.1 베타**이며, 우선 게임 본문을 한국어로 읽을 수 있도록 제작했습니다. 음성 번역과 자막, 일부 메뉴·그래픽 한글화는 이후 작업으로 남아 있습니다.

## 다운로드

이 저장소의 **Releases**에서 `v0.1` 베타를 선택하고, Assets에 첨부된 **`Hyakumonogatari_Korean_Text_v0.1.zip`**을 받으십시오.
GitHub가 자동으로 제공하는 `Source code (zip)`은 설치용 패치 파일이 아닙니다.

## 설치 방법

패치 실행 환경은 Windows이며, 별도 Python 설치나 관리자 권한은 필요하지 않습니다.

1. 지원하는 원본 CUE와 28개 BIN을 한 폴더에 준비합니다.
2. 패치 ZIP의 **내용물**을 같은 폴더에 풉니다. `Run-Patch.cmd`가 원본 CUE와 나란히 있어야 합니다.
3. `Run-Patch.cmd`를 더블클릭하고 검사가 끝날 때까지 기다립니다.
4. `SUCCESS`가 표시되면 새로 생성된 `HyakuMonogatari_Korean_Text_v0.1` 폴더 안의 CUE로 게임을 실행합니다.

원본 파일은 수정하지 않습니다. 출력 폴더에는 모든 트랙이 복사되므로 이 폴더만 옮겨 사용할 수 있습니다. 약 1GB 이상의 여유 공간을 권장합니다. 출력 폴더가 이미 있으면 덮어쓰지 않고 중단합니다.

BIOS를 수정하거나 교체하는 패치가 아닙니다. 번역용 Lua 스크립트도 필요하지 않습니다. 패치 적용 후에는 원본 게임의 에뮬레이터 즉시 저장 상태를 불러오기보다 CUE에서 정상 부팅해 주십시오.

## 지원하는 원본

**Redump에 등재된 일본판 디스크의 덤프 정보를 기준으로 제작했습니다.** 대상은 `Hyaku Monogatari - Honto ni Atta Kowai Hanashi (Japan)`의 **28 BIN + CUE** 형식입니다.
파일명과 파일 내용이 패키지의 `localization-manifest.json`에 기록된 원본과 정확히 일치해야 합니다. 단일 BIN, ISO, CHD 및 다른 덤프는 이 버전에서 직접 지원하지 않습니다.

패치 프로그램은 다음 항목을 검사합니다.

- 적용 전: 원본 전체 파일의 크기, SHA-1, SHA-256 및 패치 데이터의 SHA-256
- 적용 후: 생성된 전체 파일의 크기, SHA-1, SHA-256

검사를 통과하지 못하면 완료된 출력 폴더를 만들지 않습니다. 실패한 작업의 임시 폴더 `.hyaku-patch-partial-*`가 남을 수 있습니다. 원본 파일명을 바꾸는 것만으로 다른 덤프를 지원하게 되지는 않습니다.

## 한글화 범위

- 일반 에피소드 본문과 「속 영원한 원념」
- 학교 7대 불가사의 본문과 최초 진입 도입부
- 심령현상 지도 본문과 평가 문구
- 반각 공백·마침표·쉼표, 문단 구분 아이콘과 페이지 배치 조정
- 「속 영원한 원념」의 수동 지정 페이지 분할

총 **5,615개 검수 항목**을 적용했습니다. 이는 에피소드 수나 화면 수가 아닌 텍스트 항목 수입니다.

## 아직 포함하지 않은 내용

- 음성 시나리오 및 중간 ADPCM 음성의 번역·자막
- 타이틀 화면, 에피소드 제목, `第~話`, `~の記憶`, 일부 선택 화면 문구 등
- 「저주의 고쿠리씨」의 `コロス / ヒロコ / コロセ` 그래픽 연출
- 지도 선택 화면 지명 13개, 시스템 경고 3개, 미사용 개발용 문구 3개

음성 에피소드의 구동 확인은 음성 자막이 구현되었다는 의미가 아닙니다. 위 항목의 일본어 표시는 현재 버전의 미적용 범위입니다.

## 테스트 현황

2026년 10월 24일 기준입니다.

| 환경 | 확인 내용 | 범위 |
| --- | --- | --- |
| Mesen | 수정 디스크의 거울·과학실 구동, 새 게임에서 학교 도입부 표시, 지도 및 미나미 후편 통합 검사 | 개발 과정의 실행·글자 출력 검사. 일부 검사는 저장 상태 기반입니다. |
| SuperStation One | 일반 에피소드, 음성 에피소드, 학교 7대 불가사의, 심령현상 지도에서 현재까지 문제 없음 | 제작자의 직접 플레이에 따른 **종류별 초기 구동 결과**입니다. 전체 에피소드·모든 분기 검증은 아닙니다. |
| 원래의 PC엔진 본체 / Super CD-ROM² | 미확인 | SuperStation One의 결과를 다른 기기의 확인 결과로 확대하지 않습니다. |

SuperStation One의 펌웨어·코어 버전과 세부 설정은 이번 기록에 포함되어 있지 않습니다. 기존 CD 오디오 트랙은 변경하지 않았으며, 데이터 섹터의 EDC/ECC와 패치 결과 파일의 해시는 검사했습니다. 전체 구간의 기기별 호환성을 보증하는 정식판은 아닙니다.

## 오류 제보

저장소의 **Issues → New issue → 오류 제보** 양식을 이용해 주십시오. 양식 이용이 어렵다면 [오류 제보 항목](ERROR_REPORT.md)을 복사해 작성하셔도 됩니다.

패치 버전, 기기 또는 에뮬레이터와 버전, 에피소드명, 문제가 발생한 문구, 재현 순서를 알려 주시면 확인에 도움이 됩니다. 화면 사진이나 짧은 영상도 환영합니다. 원본 디스크 이미지와 BIOS 파일은 첨부하지 마십시오.

## 제작 과정

원문 번역과 최종 번역 검수는 제작자가 직접 진행했습니다. 게임 데이터 분석, 텍스트 추출·삽입, 한글 폰트 및 패치 코드 작성, 자동 실행 검증과 오탈자·오역 점검에는 **OpenAI Codex**를 활용했습니다. 출력 결과 검토와 SuperStation One에서의 플레이 테스트도 제작자가 직접 진행했습니다.

## 배포 구성과 글꼴

실행 프로그램(`Run-Patch.cmd`, `Apply-KoreanPatch.ps1`)과 한글화 데이터(`localization-manifest.json`, `localization-data.bin`)를 분리했습니다. 서로 다른 버전의 파일을 섞지 마십시오.

이 배포에는 원본 또는 패치 완료 디스크 이미지, BIOS, 에뮬레이터 및 즉시 저장 상태가 포함되지 않습니다. 게임 이미지와 구동에 필요한 환경은 별도로 준비해야 합니다.
